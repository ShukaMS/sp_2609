## 製品概要
### 背景(製品開発のきっかけ、課題等）
私たちの班では、留学生と日本人学生との交流の希薄さ、一人暮らしの学生の食品ロスといった学生固有の課題に対処するためのアプリを提案します。キャンパス内におけるコミュニティの垣根を越え、日常の「食」をきっかけにつながりを生み出すことを目指して開発しました。

### 製品説明（具体的な製品の説明）
余りがちな食材や料理（のこりもの）をシェア・交換できるプラットフォームです。留学生と日本人学生が言語や文化の壁を越えて手軽にコミュニケーションを取りながら、楽しくフードロスを削減できる仕組みを提供します。

機能紹介
- ①フードロスを解消するために：使い切れない食材や作りすぎてしまった料理を投稿し、近隣の学生同士で分け合えます。
- ②交流を促進するために：食材の受け渡しや料理のシェアを通じて、自然な会話や国際交流が生まれるきっかけを作ります。

### 特長
#### 1. 一人暮らしの悩み！自炊派のためのフードロス解消に役立ちます🥕
買いすぎて余らせてしまった食材や、一人分には多すぎて使い切れない調味料などを無駄なく活用できます。

#### 2. 留学生と日本人学生を「食」でつなぐボーダレスな交流🌍
料理や食材のシェアを共通の話題にすることで、語学力に自信がなくても気軽にコミュニケーションが取れる環境をつくります。

#### 3. シンプルで使いやすい直感的なUIデザイン📱
学生の日常のスキマ時間でもサクッとやり取りできるよう、迷わず直感的に操作できるシンプルな画面設計にこだわっています。

### 解決出来ること
- 一人暮らしの学生によくある「食材の余り・廃棄（フードロス）」の削減
- 学内における「留学生と日本人学生の接点不足・交流の希薄さ」の解消
- 自炊のマンネリ化防止と、学生同士の気軽な助け合い文化の醸成

### 今後の展望
- キャンパスや地域ごとのコミュニティ機能の拡張
- レシピや食材の組み合わせをAIが提案してくれるサジェスト機能の追加
- 多言語対応の強化による、よりボーダレスな利用環境の整備

### 注力したこと（こだわり等）
* ユーザー同士が安心してスムーズに受け渡しや連絡を行えるような、ストレスフリーな動線設計
* 留学生も直感的に利用できるよう、アイコンやピクトグラムを多用した親しみやすいUI/UX
