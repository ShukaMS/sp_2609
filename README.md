# たべきり冷蔵庫

[![IMAGE ALT TEXT HERE](https://jphacks.com/wp-content/uploads/2026/07/IMG_5316.png)](https://www.youtube.com/watch?v=piaNsc6ilBI)

## 製品概要
### 背景(製品開発のきっかけ、課題等）
キャンパスライフにおいて、一人で学食や自宅で食事をとるいわゆる「ぼっち飯」の孤独感や、一人暮らしの学生における食材の余剰・廃棄（食品ロス）は、多くの学生が抱える共通の課題です。また、日本人学生と留学生の間にあるコミュニケーションの壁も重なり、キャンパス内での孤立が生まれやすくなっています。私たちは、こうした課題を「食」の力で同時に解決したいと考え本アプリを開発しました。

### 製品説明（具体的な製品の説明）
「たべきり冷蔵庫」は、学内で「一人で食事をしたくない人（ぼっち飯を防ぎたい人）」と「余った食材や料理をシェアしたい人（食品ロスを防ぎたい人）」をつなぐ、ボーダレスなマッチングWebプラットフォームです。国籍や所属の垣根を越えて、誰でも気軽に「一緒にごはんを食べよう」「この食材を分け合おう」と声を掛け合える環境を提供します。

機能紹介
- **① ぼっち飯防止・お誘い機能**：学内で一緒に食べる仲間を簡単に募り、孤独になりがちな食事の時間を楽しいコミュニケーションの場に変えます。
- **② フードロス解消機能**：一人暮らしで余らせてしまった食材や作りすぎた料理をシェアし、無駄なく美味しく消費します。

### 特長
#### 1. 国籍や所属を問わず、学内の「ぼっち飯」を楽しく解消！🤝
「一人で食べるのは寂しい」「新しい友達を作りたい」という学生同士を繋げ、キャンパス内に温かい食事のコミュニティを生み出します。

#### 2. 自炊派の強い味方！余った食材のフードロスを削減🥕
買いすぎて使い切れない食材や余ったおかずをシェアすることで、学生生活の経済的な負担と食品ロスを同時に防ぎます。

#### 3. 誰でも直感的に使えるシンプルで親しみやすいUIデザイン📱
多国籍な学生が利用しても迷わないよう、ピクトグラムや直感的な操作性にこだわり、スキマ時間でサクッとつながれる設計にしています。

### 解決出来ること
- キャンパス内における「ぼっち飯」による孤独感や孤立感の解消
- 留学生と日本人学生の垣根を越えた、ボーダレスで気軽な交流の創出
- 一人暮らしの学生に多い「食材の余り・廃棄（フードロス）」の削減

### 今後の展望
- キャンパス内のリアルタイムなマッチング精度の向上
- 食材の残り具合や好みに合わせた「おすすめの献立・シェア相手」の自動サジェスト機能
- 多言語対応のさらなる拡充による、よりインクルーシブな利用環境の構築

### 注力したこと（こだわり等）
* ユーザー同士が気軽に、かつ安心して「一緒に食べよう」「シェアしよう」と声を掛け合える心理的安全性の高いUI/UX設計
* 国籍を問わずすべての学生が直感的に操作できる、シンプルで分かりやすい画面レイアウトの追求
