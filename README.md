
# 🍳 のこりものクラブ

### 冷蔵庫から、はじまる出会い。

**「のこりものクラブ」** は、余った食材をきっかけに大学生同士の新しい出会いを生み出す、マッチングWebアプリです。

🌐 **[Webアプリはこちら](https://shukams.github.io/sp_2609/implementation/)**

---

## 製品概要

### 背景（製品開発のきっかけ・課題）

大学生活では、一人暮らしや新しい環境への適応などにより、一人で食事をする機会が多くなりがちです。

「誰かと一緒にご飯を食べたい」「新しい友達を作りたい」と思っていても、初対面の人に声をかけることには心理的なハードルがあります。

また、留学生が日本人学生と接する機会が十分でないという声も多く上がっています。

一方、一人暮らしでは購入した食材を使い切れず、食品ロスが発生することもあります。

私たちは、**余った食材を学生同士をつなぐきっかけに変えることで、食事の孤独感と食品ロスという2つの課題を解決できるのではないか**と考え、本アプリを開発しました。

### 製品説明

「のこりものクラブ」は、一人で食事をすることに寂しさを感じる大学生や、新しい友人を作りたい学生を対象とした、食材を活用したマッチングWebアプリです。

また、学生はモデルでは北海道大学の学生に限定しているので、学内で長期的に関われる友人を作ることができます。

ユーザーが冷蔵庫の食材と賞味・消費期限を登録すると、期限までの残り日数や、手持ちの食材で作れるレシピを表示します。

**最大の特徴は、学生同士の余った食材を組み合わせ、一緒に料理できる相手やメニューを提案するマッチング機能です。**

例えば、キャベツを持つ学生と卵を持つ学生がマッチングすると、両者の食材を活用できる料理を提案します。

また、自分で料理会を企画し、他の学生を募集することもできます。

料理という共通の目的を通じて自然な学内交流を生み出すとともに、余った食材の有効活用によって食品ロス削減にも貢献します。

## 特長

### 1. 🤝 食材をきっかけとしたマッチング機能

一般的なマッチングアプリとは異なり、ユーザーが所有する食材を組み合わせて、一緒に料理できる相手を提案します。

初対面でも「何を作るか」という共通の目的があるため、会話や交流を始めやすいことが特徴です。

### 2. 🍳 学内の料理会を通じた交流

ユーザーは料理会を企画し、以下の情報を登録できます。

- 開催日時
- 開催場所
- 参加定員
- 料理メニュー
- 持参する食材
- 参加者

日本人学生や留学生など、普段接する機会の少ない学生同士が、一緒に料理を作り、食事を楽しむきっかけを提供します。

### 3. 🥕 冷蔵庫管理とレシピ提案

食材について以下の情報を登録できます。

- 食材名
- 数量
- 保存場所（冷蔵・冷凍・野菜室・常温）
- 賞味期限・消費期限
- メモ

期限までの残り日数を表示するとともに、登録された食材を活用できるレシピを提案します。

余った食材を無駄なく使うことを支援します。

### 4. 📊 食品ロスの可視化

食材を「使い切った」「捨てた」と記録することができます。

記録をもとに、以下の情報を表示します。

- 食材の使い切り率
- 使い切った食材の件数
- 廃棄した食材の件数
- よく廃棄してしまう食材
- 最近の使用・廃棄履歴

自身の食生活を振り返ることで、食品ロスへの意識を高め、買いすぎや廃棄の予防につなげます。

### 5. セキュリティもバッチリ！

1. なりすまし対策：北海道大学のメールで認証し、学外のメールアドレスは遮断します。
2. ストーカーなどの異性トラブル対策：「同性のみ」の設定で異性とのトラブルへの不安を解消。
3. 個人情報の公開の範囲：冷蔵庫内の状況は「期限3日以内」「マッチON」のときだけ共有。
4. メッセージの無害化：定型文のみ使用でき、スクリプトの埋め込みも防ぐ。

## 解決できること

- **ぼっち飯による孤独感の軽減**
  - 一人で食事をする大学生が、一緒に料理や食事を楽しむ仲間を見つけられる。

- **学内交流の促進**
  - 日本人学生と留学生を含む学生同士が、料理をきっかけに自然に交流できる。

- **食品ロス削減**
  - 一人では使い切れない食材を、他の学生と組み合わせて有効活用できる。

- **食材管理の効率化**
  - 冷蔵庫内の食材や期限を可視化し、食材の使い忘れを防ぐ。

## 今後の展望

### 1. リアルタイムマッチングの実現

現在のブラウザ内でのデータ管理から発展させ、学生同士の食材や空き時間をリアルタイムで共有できる仕組みを構築します。

### 2. マッチング精度の向上

食材だけでなく、以下の情報も考慮したマッチングを目指します。

- 空き時間
- 料理の好み
- 希望する参加人数
- 食材の賞味・消費期限
- 調理可能な場所

### 3. 多言語対応

日本人学生だけでなく、留学生も気軽に利用できるよう、多言語対応を進めます。

### 4. 安心・安全な利用環境の整備

- 大学メールアドレスによる本人確認
- 料理会の参加者管理
- 食物アレルギーへの配慮
- 食材の衛生管理
- 安全な開催場所の確保

### 5. 食品ロス削減効果の検証

実際の食材使用量や廃棄量を記録し、食品ロス削減への効果を検証します。

## 独自技術

### ハッカソンで開発した独自機能・技術

#### 1. 食材ベースのマッチングロジック

ユーザーが登録した食材を活用し、一緒に料理できる相手やメニューを提案する仕組みを開発しました。

プロフィールだけでなく、食材という共通の目的を通じてマッチングする点が特徴です。

登録された食材とレシピの必要食材を照合し、調理できる料理を提示します。

また、使い切り・廃棄の記録から使い切り率を算出し、食品ロスを振り返る仕組みを実装しました。

#### 4. 料理会の企画・参加機能

日時・場所・参加人数・持参食材などを登録し、料理を通じた学内交流の機会を作ります。

## 現在の実装について

現在のアプリは、HTML・CSS・JavaScriptを中心に開発したWebアプリです。

主要なデータはブラウザのLocalStorageに保存しています。

実際の複数ユーザー間でのリアルタイムなマッチングやデータ共有は、今後の開発課題です。
